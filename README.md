# IntuScribe Desktop

AI medical scribe for Windows: record a consultation, generate a clinical note, and push it into your EHR.

## Download

**[Download the latest installer for Windows](https://github.com/Rid0715/intuscribe-releases/releases/latest/download/IntuScribe-Setup.exe)**

All versions: [Releases](https://github.com/Rid0715/intuscribe-releases/releases)

## Install

1. Run `IntuScribe-Setup.exe` and choose an install folder (no admin rights needed).
2. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**.
   The installer is not yet code-signed, so SmartScreen warns about it.
3. Sign in with your IntuNotes account.

## Requirements

- Windows 10 or 11 (64-bit)
- A microphone
- An IntuNotes account — [intuscribe.com](https://intuscribe.com)

Push to EHR and Dictate into field are Windows-only. On Mac, use the IntuScribe Chrome extension.
